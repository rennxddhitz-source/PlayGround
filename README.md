# 🧸 Toys vs. Nightmares — Guardian of Dreams 🛡️

**Jadilah Guardian tak terkalahkan! Lindungi tidur si kecil dari serangan mimpi buruk.**

Game bergenre RPG / Idle ini dikembangkan secara mandiri.

---

## 🎮 Cara Bermain
- Kumpulkan **Bulan (🌙)** dan **Permata (💎)** untuk meningkatkan kekuatanmu.
- Selesaikan berbagai **Malam** dan kalahkan bos mimpi buruk.
- Rekrut karakter dan naikkan level untuk menjadi Guardian terkuat!
- Jangan lupa klaim **Bonus Harian** setiap hari.
